# Lessons Archive

This file holds lessons learned from older phases, extracted from PROJECT.md to keep the main file lean.

**How to use**:
- New lessons are always written to PROJECT.md (Section 13 — Recent Lessons) at phase close-out.
- When Recent Lessons exceeds ~10 entries, compress multi-line entries first; if still too large, move older entries here.
- Add this file to PROJECT.md's Subdocuments registry (Section 14) so it loads when relevant.
- Group lessons by phase range or milestone for easy scanning.
- When this file grows large, add a second archive file (`project/lessons-archive-v2.md`) as a new registry row.
- Full detail for any lesson: `planning/phase-NN/POSTMORTEM.md`
